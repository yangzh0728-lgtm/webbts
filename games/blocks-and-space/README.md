# Blocks & Space website copy

The four game files in this directory are copied from Sam Yang's
`yangzh0728-lgtm/blocks-and-space` repository at commit
`e3ea4d16a834fb34525fbe2d1fd4e5b7602ede21`.

The project page is `/webbts/tetris_project.html`; the standalone game is
`/webbts/games/blocks-and-space/`. The game interface is in English.

This is a static snapshot, not an automatic synchronization. To update it, copy
`index.html`, `styles.css`, `engine.js`, and `app.js` from the source repository,
preserve the English interface, run that repository's engine and economy tests, and verify both the embedded
and standalone game. Keep this source revision current.
